# Blair Motors — free static website starter

This is a responsive, single-page website starter for Blair Motors. It uses plain HTML, CSS and JavaScript; no paid builder or framework is required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a free account at https://github.com/ if you do not already have one.
2. Create a new public repository named `blair-motors`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. GitHub will provide a public website address after deployment.

## Before publishing
- Replace the placeholder email addresses in `index.html` with verified Blair Motors contact addresses.
- Review all copy and confirm that it reflects the company's current position.
- The vehicle illustration is an original CSS concept graphic, not a representation of a completed or validated vehicle.
- The website intentionally does not claim completed testing, production, validated performance, or a completed Ugandan subsidiary incorporation.
- The Google Fonts import requires an internet connection; the site still works with fallback fonts if unavailable.

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current year
